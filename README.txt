翻聖經大賽 正式版 2.1 經文揭曉版
============================

功能：
- 完整 66 卷
- 完整 1,189 章
- 完整 31,102 節
- 每章依正確節數抽選
- 完全離線運作
- 經文不重複
- 重新整理後保留紀錄
- 搜尋與清除紀錄
- 電腦、投影幕及手機自動排版

部署方式：
1. 解壓縮。
2. 將 index.html、style.css、script.js、bibleData.js
   放在 GitHub Repository 的同一層。
3. 在 GitHub Desktop 執行 Commit to main。
4. 執行 Push origin。
5. 等待約 1～2 分鐘後重新整理 GitHub Pages。

資料驗證：
- 書卷：66
- 章數：1189
- 節數：31102


2.1 新增：
- 抽選後增加「經文內容」區
- 預設以馬賽克遮住
- 按「顯示經文」才揭曉
- 可再次按下隱藏
- 經文文字會暫存在瀏覽器，已載入過的內容可快速再次顯示

注意：
- 抽選、節數與紀錄功能仍可離線使用。
- 經文內容第一次載入需要網路連線。
- 經文文字使用 Chinese Union Version（CUV）。
